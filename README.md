# ZhaohuaTypewriter-Webfont
本專案為朝華打字機（ZhaoHua Typewriter）的非官方woff2版，提供jsDelivr網址以便嵌入進CSS。

原作者：特里王（Terry Wang）
```
@font-face {
  font-family: "Zhaohua-Typewriter";
  font-display: swap;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/KHScara/ZhaohuaTypewriter-Webfont@main/朝華打字機.woff2") format("woff2");
}

@font-face {
  font-family: "Pozhen-Typewriter";
  font-display: swap;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/KHScara/ZhaohuaTypewriter-Webfont@main/迫真打字油印體.woff2") format("woff2");
}

@font-face {
  font-family: "Youcha-Sanzi";
  font-display: swap;
  font-style: normal;
  src: url("https://cdn.jsdelivr.net/gh/KHScara/ZhaohuaTypewriter-Webfont@main/油茶饊子體.woff2") format("woff2");
}
